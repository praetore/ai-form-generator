# AI Form Generator

Een moderne webapplicatie voor het dynamisch genereren van formulieren met behulp van AI-technologie. Gebouwd met Next.js en React.

## Belangrijkste kenmerken

- Dynamische formuliergeneratie via AI
- Moderne UI met Tailwind CSS en shadcn (via `@rjsf/shadcn`)
- TypeScript voor type-veiligheid
- React JSON Schema Form (RJSF) integratie

## Technologieën

- **Frontend Framework**: Next.js
- **UI Framework**: React
- **Styling**: Tailwind CSS + shadcn theme (`@rjsf/shadcn`)
- **Formulier Management**: RJSF (`@rjsf/core`, `@rjsf/shadcn`, `@rjsf/validator-ajv8`)
- **Type Checking**: TypeScript

### Vereisten

- Node.js (LTS versie aanbevolen)
- npm of yarn package manager
- `OPENAI_API_KEY` (OpenRouter) in `.env.local`

### Starten

```bash
npm install
npm run dev
```
